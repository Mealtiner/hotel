# GARRY – Kategorie a srovnání

Vícejazyčné kategorie pokojů jako karty a srovnávací tabulka.

## Historie změn

### 1.8.0 — 2026-09-07
- Záhlaví obou tabulek má `scope="col"` (WCAG 1.3.1).

### 1.7.0 — 2026-09-07
- Název kategorie v kartě je `<h2>` místo `<h3>` — karty stojí přímo pod nadpisem sekce, takže úroveň h3 přeskakovala stupeň osnovy (WCAG 1.3.1).
