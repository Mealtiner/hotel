# GARRY Příspěvkový carousel – roadmap

## Cíl

Převést Elementor carousel na univerzální, přístupnou a výkonnou komponentu.

## Současný stav

- verze 1.2.3, Framework 2.3 a LocalLog;
- Elementor widget s mapováním ACF; bez shortcode, bloku a Divi modulu.

## Roadmap

1. Oddělit query, ACF mapování, HTML karty, carousel engine a assets.
2. Přidat shortcode garry_prispevkovy_carousel a dynamický blok.
3. Přidat Divi 4/5 modul; Elementor widget zachovat jako tenký adapter.
4. Doplnit keyboard ovládání, focus management, reduced motion, lazy load a bezpečný fallback bez JavaScriptu.
5. Testovat taxonomie, prázdný stav, mobil, více carouselů a cache.

## Akceptace

Carousel funguje ve WordPressu bez Elementoru a ve všech builder plochách má stejné filtrování a přístupnost.
